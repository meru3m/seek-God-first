# Music Files

This directory should contain calm piano/instrumental MP3 files.

For a free music file, you can:
1. Download from https://freemusicarchive.org/
2. Use YouTube Audio Library (https://www.youtube.com/audiolibrary/music)
3. Get free tracks from https://incompetech.com/

Place your music file as `calm-piano.mp3` in this directory.

Example free piano tracks you can search for:
- "Peaceful Piano"
- "Calm Instrumental"
- "Meditation Music"
